# tic-tac-toe

A simple game of tic tac toe

# How it's made

**Tech Used**: HTML, CSS, and JavaScript

I started by building the functionality of the game in the console and
using factory functions and IIFEs to encapsulate everything. I created
a gameboard module to hold the board itself, a cell module for individual
cells, and a gameController module for dealing with all the logic of playing
the game. Once I got it playable in the console, I moved on to creating a
module for rendering the game into visible DOM elements. Then, I added the ability
to change player names and also start the game itself and restart it. Because I started
building it by making sure it worked in the console and made everything modular, the
workflow was quite easy and seamless as the project progressed, making each next step
make sense.

This was probably the hardest project I've done in Odin. There was a lot of planning
